# Script Studio

موقع عربي RTL لإنشاء سكريبتات يوتيوب طويلة وShorts باللهجة المصرية باستخدام OpenAI API.

## التشغيل على Windows 10

1. ثبّت Node.js إصدار LTS من https://nodejs.org
2. فك ضغط المشروع وافتح المجلد.
3. افتح CMD داخل المجلد ونفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` وسمّ النسخة `.env`.
5. افتح `.env` وضع مفتاح API الخاص بك:
   ```env
   OPENAI_API_KEY=مفتاحك_هنا
   OPENAI_MODEL=gpt-5.5
   PORT=3000
   ```
6. شغّل الموقع:
   ```bash
   npm start
   ```
7. افتح http://localhost:3000

## ملاحظات مهمة

- لا تضع مفتاح API داخل ملفات `public` أو تشاركه مع أي شخص.
- المفتاح يُقرأ على الخادم فقط من ملف `.env`.
- استخدام API قد يترتب عليه تكلفة حسب حسابك واستهلاكك. راجع لوحة استخدام وفوترة OpenAI.
- المشاريع محفوظة محليًا في متصفح الجهاز عبر localStorage؛ ليست مزامنة سحابية ولا يوجد نظام حسابات في هذه النسخة.
- يمكنك تغيير النموذج من `OPENAI_MODEL` حسب النماذج المتاحة لحساب API لديك.
